某小厂，待遇还不错，但是老板有点学历歧视，好像是被9✌🏻横向了😭
一、 个人背景与项目深挖
1、请做一个自我介绍。
2、你在小米做的这个电视客诉分析 Agent，底层使用的是什么框架？
3、能否详细讲讲在小米项目中，你观察到的一个 Agent 效果上的具体问题，以及你们最终是怎么迭代和改进的？
4、项目中引入了哪些外部知识召回手段（如 RAG、CodeGraph）？各自解决什么问题？
二、 Agent 框架与底层架构
1、你怎么理解 LangChain、LangGraph 以及手写或其他 Agent 框架之间的区别？
2、LangChain 和 LangGraph 在设计理念和应用场景上有什么核心区别？
3、你是怎么理解 Agent Harness 的？一个标准的 Harness 一般包含哪些核心模块？
三、 上下文管理与记忆系统
1、在多轮交互或复杂任务执行中，如果上下文过长（超过 Token 预算），有哪些具体的上下文压缩策略？
2、你们的 Agent 系统里有 Memory（记忆）相关的设计吗？具体是如何落地的？
四、 Agent 评测与效果优化
1、你平时会怎样去评测一个 Agent 的实际效果？一般从哪些指标或角度去做针对性优化？
2、如果面对的是没有标准答案的开放式场景（例如长文档/规划书生成），你认为应该如何去进行质量评测？
五、 开源生态与工程机制
1、你平时了解或使用过哪些开源 Agent 框架/工具（如龙虾 OpenClaw、Hermes Agent 等）？它们与普通 Agent 相比有什么独特设计？
2、在这类 Agent 中，“主动给用户推送消息”（而非传统的一问一答）机制通常是如何实现的？
六、 技术栈
1、除了 Agent 相关的开发，你在后端开发或者其他技术栈上有哪些实践经验？
